
# 🚀 AdFlow Pro – Modern Marketplace Web App

Welcome to **AdFlow Pro** 🎯  
A modern, responsive online marketplace web application where users can browse, post, and manage advertisements easily.



## 🌐 Live Demo
https://midterms-nu.vercel.app/



## 📌 About the Project

AdFlow Pro is a marketplace-style web application inspired by modern classified platforms.

It allows users to:
- Browse product advertisements
- View ad details
- Post new ads
- Manage listings via dashboard
- Search and filter products easily



## ⚙️ Tech Stack

- React (Frontend)
- TypeScript
- Vite
- Tailwind CSS
- Node.js
- Git & GitHub
- Vercel



## ✨ Features

- 🛒 Modern marketplace UI
- 📱 Fully responsive design
- 🔍 Search & category filtering
- 🧾 Ad detail pages
- ➕ Post new ads functionality
- 📊 User dashboard system
- ⚡ Fast performance
